# Working on Badge Buddy

For version updates, release preparation, or publication, read [the release assistant routine](docs/release/assistant.md), then follow its linked release procedure and verification instructions. It supports guided preparation and explicitly authorized autonomous releases. Read the user's current scope before acting; a request to prepare a release is not a request to publish it.

Keep repository instructions portable. Do not commit machine-specific paths, account inventories, credential locations or values, private-key details, or private session handoffs. Discover local prerequisites as needed and keep private operational notes outside tracked files. Public release keys and project configuration already tracked by this repository remain the project's source of truth.

Use [CONTRIBUTING.md](CONTRIBUTING.md) for development and validation. Preserve unrelated work and use an isolated checkout when release operations would disturb it. Follow the user's existing authorization without asking for the same permission at every step.
